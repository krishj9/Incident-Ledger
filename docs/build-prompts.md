     begin new session for the authenticated user. Audit log the switch.
   - POST /v1/devices/register → register device installation.

   - register_device, count_active_devices_for_center, get_device_by_installation_id

6. app/audit/writer.py:

     incident_id=None, report_version_id=None, correlation_id, metadata={})

   - Call this for: session_switch, device_register

- No self-registration: if external_subject doesn't map to a users row, return 401.
- Require explicit sign-in: never identify user solely by device.
